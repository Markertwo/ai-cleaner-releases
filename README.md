# AI 项目空间清理器 · 更新发布

本仓库用于发布 AI 项目空间清理器 的正式程序包及更新清单，应用可匿名检查与下载。源码保存在私有源码宝箱。

下载版本为 1.1.5。GitHub Releases 中的校验材料用于核对下载完整性。

## 下载

请在 [Releases](https://github.com/Markertwo/ai-cleaner-releases/releases/latest) 下载。选择 `AIProjectCleaner.exe`，只支持 Windows 10 / 11，独立窗口依赖 Edge 或 Chrome。

程序尚未签名，首次运行可能出现 Windows 安全提示；请先核对同一 Release 的 `SHA256SUMS.txt`。遇到疑似误报请反馈，勿关闭系统防护。

## 反馈

在 [Issues](https://github.com/Markertwo/ai-cleaner-releases/issues) 提供版本、Windows 版本、复现步骤和截图；提交前遮挡项目路径、学习记录等个人信息。
